# Sibyl Mobile — legacy experiment

> **Unsupported:** this application implements an earlier token/grid and ghost-rendering experiment. It is not the current Paper Stamp Protocol v2 client and is not part of Sibyl's current security claim.

The code is retained temporarily as research history. See [`docs/legacy.md`](../../docs/legacy.md) for the boundary between legacy and current code.

## Experimental flows preserved here

- Device-key registration and challenge-signature authentication.
- Calibration and randomized numeric input.
- Token-stream envelope transport.
- Ghost receive rendering and an earlier multi-device ceremony.
- Reference native modules for screen hardening and buffer clearing.

Use `apps/helper-web` for the current paper-stamp prototype.
